# CEO Demo V2 Presenter Script — 5–6 minutes

## 0:00–0:45 — The setup is over

Open `/demo`, frame the bar, then start the golden path:

“Gmail tracking is already implemented. The question now is: does Arjun still have to manage the job search? In this version, AmbitionBox does the work first and asks only when it genuinely needs him.”

On Today, point to the monitoring status, the 15 applications, and the activity spine. Open the prepared Juspay follow-up.

## 0:45–2:05 — The chasing is handled

“Juspay has been quiet for five days. AmbitionBox checked the thread and Arjun’s verified evidence, then prepared the right follow-up. It still has not sent anything.”

Grant the scoped permission and click **Approve and send**.

“The scope is exact: AmbitionBox may send only a message Arjun has seen and approved. Now it owns the monitoring loop.”

Advance three days.

## 2:05–3:10 — Ask only what cannot be known

“The recruiter’s reply contains one claim the system cannot safely infer: did Arjun personally own Java services for three years?”

Choose **Not quite**.

“A weaker product would optimise for a perfect score. This one keeps the gap visible and uses the strongest confirmed evidence instead.”

Approve the honest reply and open the interview update.

## 3:10–4:25 — The work arrives before the task

“Arjun does not click ‘build my prep plan.’ The invitation arrived, so the plan is already here—built from the role, 847 reviews, interview reports, and his confirmed Razorpay evidence.”

Start the highest-impact practice, use the demo answer, get coaching, and save it.

## 4:25–5:40 — The offer becomes a decision

Jump to offer day.

“The ₹28L headline is not the decision. AmbitionBox has already separated fixed, variable, and one-time pay; compared the offer with Arjun’s ₹15L current pay, ₹22L target, and the ₹24–30L market; and prepared a credible ask.”

Open negotiation, review the exact message, and approve it.

Close on the full timeline:

“Negotiation sent. AmbitionBox is watching the thread. The job search kept moving without becoming Arjun’s second job.”

## Recovery

- Use browser Back to return to Today; progress persists.
- Use `/demo` to jump to any stable chapter preset.
- **Reset to post-import** restores the opening state.
- No real Gmail account or message is involved.
