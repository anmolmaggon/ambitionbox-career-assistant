# Reference Inbox

Drop new screenshots and other intentional design references in this folder.

Files here are **unprocessed**. Before using one for design work, Codex or Claude must:

1. inspect the original;
2. move it to a stable folder and descriptive filename under `references/`;
3. calculate its SHA-256 checksum;
4. add provenance, applicable screen/layer, learning, non-learning, and status to `references/CATALOG.md`;
5. record durable owner feedback in `context/FEEDBACK.md` when relevant.

`npm run verify:context` fails while any file other than this README or operating-system metadata remains here. That prevents an uploaded reference from being silently overlooked.
